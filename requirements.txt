## 🚀 DÉPLOIEMENT SUR RAILWAY

### **Méthode 1 : Via GitHub (recommandé)**

1. **Crée un nouveau repo GitHub** ou utilise l'existant
2. **Upload tous les fichiers** du zip
3. **Railway** redéploie automatiquement
4. ✅ Terminé !

---

### **Méthode 2 : Railway CLI**

```bash
# 1. Décompresse le zip
unzip botanus_v12.8.zip
cd botanus_v12.8

# 2. Initialise Railway
railway login
railway link

# 3. Deploy
railway up
```
